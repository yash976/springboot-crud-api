# Spring Boot CRUD API

A simple and clean **RESTful CRUD API** built using **Spring Boot**, **Spring Data JPA**, and **MySQL**.

---

## 🚀 Features

- Create Employee  
- Read All Employees  
- Read Employee by ID  
- Update Employee  
- Delete Employee  
- Layered Architecture (**Controller → Service → Repository → Entity**)

---

## 🛠 Tech Stack

- **Java 17**
- **Spring Boot**
- **Spring Web**
- **Spring Data JPA**
- **MySQL**
- **Maven**
